# SEO titles & meta descriptions — GNT Landscaping

Copy-paste ready. Every **title is 50–60 characters** with the primary keyword at
the front. Every **description is 150–160 characters**, leads with the primary
keyword, and closes on a 📞 call-to-action carrying (724) 712-3619. All 33 titles
and 33 descriptions are unique.

**Geo targets:** Cranberry Township PA (primary) · Butler County PA · Allegheny
County PA · Jackson Twp · Marion Twp · Daugherty Twp.

Two caveats on the emoji: Google strips emoji from meta descriptions more often
than it keeps them, so treat the 📞 as upside rather than a guarantee — the copy
still reads correctly without it. And the phone number is already in the
LocalBusiness schema, so a call button can appear whether or not the emoji does.

Separators are plain hyphens rather than em dashes so strings paste cleanly.
